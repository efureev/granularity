# Токены и темизация

Пакет не заводит своей палитры: цвета, радиусы, кегли и длительности приходят из
ядра (`--gr-*`). Свои переменные — только точки кастомизации самих компонентов,
и каждая объявлена в `tokens.json` рядом с компонентом, откуда попадает в
документацию и в гейт.

## Свои токены

| Токен | Дефолт | Что задаёт |
| --- | --- | --- |
| `--gr-calendar-bg` | `var(--gr-card)` | Фон панели календаря |
| `--gr-calendar-padding` | `0.75rem` | Внутренний отступ панели |
| `--gr-calendar-selected-bg` | `var(--gr-primary)` | Заливка выбранного дня |
| `--gr-calendar-selected-fg` | `var(--gr-primary-fg)` | Текст выбранного дня |
| `--gr-calendar-hover-bg` | `var(--gr-muted)` | Подсветка дня под курсором |
| `--gr-calendar-today-ring` | `var(--gr-primary)` | Обводка сегодняшнего дня |
| `--gr-calendar-outside-fg` | `var(--gr-muted-fg)` | Дни добора соседних месяцев |
| `--gr-calendar-range-bg` | `var(--gr-muted)` | Полоса выбранного периода |
| `--gr-time-picker-column-height` | `12rem` | Сколько значений видно в колонке разом |
| `--gr-time-picker-selected-bg` | `var(--gr-primary)` | Заливка выбранного значения |
| `--gr-time-picker-selected-fg` | `var(--gr-primary-fg)` | Текст выбранного значения |
| `--gr-time-picker-hover-bg` | `var(--gr-muted)` | Подсветка значения под курсором |
| `--gr-time-picker-active-ring` | `var(--gr-ring)` | Кольцо клавиатурного курсора |

Все они — `hook`: CSS для них не генерируется, и `var(--gr-x, дефолт)` падает на
дефолт, пока тема не сказала иначе. Переопределяются как любые CSS-переменные:

```css
[data-theme='dark'] {
  --gr-calendar-range-bg: color-mix(in srgb, var(--gr-primary) 18%, transparent);
}
```

## Состояния читаются не только цветом

Выбранный день несёт заливку, «сегодня» — обводку, клавиатурный курсор в колонке
— кольцо. Это требование WCAG 1.4.1, и оно же причина, по которой курсор и выбор
не делят один визуальный признак: при совпадении они слились бы в одно.

## Что переопределять нельзя

Кегли, радиусы и длительности задаются токенами ядра
(`--gr-control-text-*`, `--gr-radius-*`, `--gr-duration-*`, `--gr-ease-*`) — в
разметке пакета нет ни пиксельных литералов, ни утилит uno-шкалы вроде
`text-sm`. Это держит гейт `styleTokens`: утилита выглядит правильно, но темой
не настраивается, и потому запрещена наравне с литералом.

## Сборка CSS

Классы пакета попадают в CSS через `presetGranular`: провайдер
`@feugene/granularity-chrono/granular-provider` отдаёт пресету и safelist, и
директории для скана. Подключается он рядом с провайдером ядра:

```ts
providers: [granularityProvider, granularityChronoProvider]
```

Компонент, выбранный потребителем, приносит с собой всё, что рендерит:
`GrDateTimePicker` — сетку, колонки, поповер и кнопки ядра. Граф объявлен в
`config.ts` каждого компонента и проверяется `granular doctor --strict`.
