# Токены и темизация

Пакет не заводит своей палитры: цвета, радиусы, кегли и длительности приходят из
ядра (`--gr-*`). Свои переменные — только точки кастомизации самих компонентов,
и каждая объявлена в `tokens.json` рядом с компонентом, откуда попадает в
документацию и в гейт.

## Свои токены

Токены двух видов. **`theme`** — решение дизайна: значение даёт тема, у каждой темы каталога оно своё
(`components/@feugene/granularity-chrono/<Компонент>/` в пакете токенов), компонент читает его без
запасного значения. **`hook`** — ручка приложения: CSS для неё не генерируется, и `var(--gr-x, дефолт)`
падает на дефолт, пока приложение не скажет иначе. В таблице дефолт — значение «Сланца» для `theme`
и запасное значение для `hook`.

| Токен | Вид | Дефолт | Что задаёт |
| --- | --- | --- | --- |
| `--gr-calendar-bg` | hook | `var(--gr-card)` | Фон панели календаря |
| `--gr-calendar-padding` | hook | `0.75rem` | Внутренний отступ панели |
| `--gr-calendar-cell-size` | hook | `1.75rem`…`2.5rem` по `size` | Сторона ячейки дня; для узкой карточки — `min(2.25rem, 12cqi)` |
| `--gr-calendar-selected-bg` | hook | `var(--gr-selected)` | Заливка выбранного дня — роль выбора, как у отметок ядра |
| `--gr-calendar-selected-fg` | hook | `var(--gr-selected-fg)` | Текст выбранного дня |
| `--gr-calendar-outside-fg` | hook | `var(--gr-muted-fg)` | Дни добора соседних месяцев |
| `--gr-calendar-hover-bg` | theme | `var(--gr-muted)` | Подсветка дня, периода и стрелок листания под курсором |
| `--gr-calendar-today-fg` | theme | `var(--gr-fg)` | Число «сегодня» и текущего периода |
| `--gr-calendar-today-weight` | theme | `normal` | Начертание «сегодня»; держится и на выбранном дне |
| `--gr-calendar-today-ring` | theme | `var(--gr-primary)` | Обводка «сегодня»; `transparent`, если тема отмечает его числом |
| `--gr-calendar-title-weight` | theme | `600` | Начертание заголовка месяца, года, десятилетия |
| `--gr-calendar-range-bg` | theme | `var(--gr-muted)` | Полоса выбранного периода |
| `--gr-calendar-range-preview-bg` | theme | `var(--gr-muted)` | Полоса предпросмотра — до дня под курсором, пока конец не выбран |
| `--gr-calendar-preview-end-bg` | theme | `var(--gr-selected)` | Заливка дня под курсором, ещё не выбранного |
| `--gr-calendar-preview-end-fg` | theme | `var(--gr-selected-fg)` | Его число |
| `--gr-calendar-preview-end-ring` | theme | `transparent` | Его обводка — признак края у темы, которая край не заливает |
| `--gr-time-picker-column-height` | hook | `12rem` | Сколько значений видно в колонке разом |
| `--gr-time-picker-selected-bg` | hook | `var(--gr-selected)` | Заливка выбранного значения |
| `--gr-time-picker-selected-fg` | hook | `var(--gr-selected-fg)` | Текст выбранного значения |
| `--gr-time-picker-active-ring` | hook | `var(--gr-ring)` | Кольцо клавиатурного курсора |
| `--gr-time-picker-hover-bg` | theme | `var(--gr-muted)` | Подсветка значения под курсором |

«Глина» заливает выбор графитом, отмечает «сегодня» числом глиной и полужирным без обводки, подсвечивает
наведение полупрозрачным графитом — как пункты списков ядра, — а день под курсором при выборе периода
обводит, не заливая. Своя тема, наследующая «Сланец» (`extends`), получает его значения сама; копия
задаёт их явно, нехватку называет `granum doctor`.

Переопределяются оба вида как любые CSS-переменные — приложение сильнее темы:

```css
/* тёмные режимы любой темы — по суффиксу пары */
[data-theme$="-dark"] {
  --gr-calendar-range-bg: color-mix(in srgb, var(--gr-primary) 18%, transparent);
}
```

Месяц на `md` занимает около 290px, с номерами недель — 309px: в карточку
телефона он без хука не помещается. `--gr-calendar-cell-size` уменьшает ячейку
вместе с панелью пикера; ячейку меньше 24px (WCAG 2.2 «Target Size») делать не
стоит:

```css
.phone-card {
  container-type: inline-size;
  --gr-calendar-cell-size: max(1.5rem, min(2.25rem, 12cqi));
}
```

## Состояния читаются не только цветом

Выбранный день несёт заливку, «сегодня» — обводку или начертание (решает тема),
клавиатурный курсор в колонке — кольцо. Это требование WCAG 1.4.1, и оно же причина,
по которой курсор и выбор не делят один визуальный признак: при совпадении они слились
бы в одно.

## Что переопределять нельзя

Кегли, радиусы и длительности задаются токенами ядра
(`--gr-control-text-*`, `--gr-radius-control-*`, `--gr-duration-*`, `--gr-ease-*`) — в
разметке пакета нет ни пиксельных литералов, ни утилит uno-шкалы вроде
`text-sm`. Скругление дня и краёв полосы идёт за ступенью: `--gr-radius-control-<ступень>`. Это держит гейт `styleTokens`: утилита выглядит правильно, но темой
не настраивается, и потому запрещена наравне с литералом.

## Сборка CSS

Классы пакета попадают в CSS через granum: на сборке пакета плагин извлекает их
по графу бандла и пишет в `dist/granum.manifest.json` вместе с CSS компонентов и
потребляемыми токенами. Приложение перечисляет пакет по имени рядом с ядром и
читает готовый манифест, а не сканирует `dist`:

```ts
providers: ['@feugene/granularity', '@feugene/granularity-chrono']
```

Компонент, выбранный потребителем, приносит с собой всё, что рендерит:
`GrDateTimePicker` — сетку, колонки, поповер и кнопки ядра. Граф объявлен в
`config.ts` каждого компонента, сборка сверяет его с фактическими импортами
(`UndeclaredDependencyError`), а замыкание проверяет `granum doctor --strict`.
