# GrDateTimePicker

Сетка месяца и колонки времени в одной панели. Здесь же живёт `autoApply`: выбор
многошаговый, и «применить» перестаёт быть тавтологией.

Форма значения и `valueAdapter` — [`../model.md`](../model.md), клавиши —
[`../keyboard.md`](../keyboard.md), токены — [`../theming.md`](../theming.md),
серверный рендер — [`../ssr.md`](../ssr.md).

```vue
<GrDateTimePicker v-model="startsAt" :auto-apply="false" />
```

## Когда брать

- **момент, а не день** — начало встречи, дедлайн, время публикации: дата без
  времени здесь означала бы полночь, чего пользователь не имел в виду;
- **выбор из нескольких шагов** — день, час, минута; `autoApply: false` даёт
  подтверждение, чтобы значение не уезжало после первого же клика;
- **нужны секунды** — `enableSeconds` добавляет третью колонку;
- **на бэкенд уходит строка** — `valueAdapter="isoDateTime"` отдаёт
  `'2026-08-12T14:30:00'` без смещения: это то, что человек видит на часах.

## Когда взять другое

| Нужно | Берите |
| --- | --- |
| Только дата | [`GrDatePicker`](./GrDatePicker.md) |
| Только время | [`GrTimePicker`](./GrTimePicker.md) |
| Период «с — по» | [`GrDateRangePicker`](./GrDateRangePicker.md) |
| Сетка месяца без поля | [`GrCalendar`](./GrCalendar.md) |
| Показать момент, а не выбрать | [`GrRelativeTime`](./GrRelativeTime.md) |

Период **с временем на границах** этот пакет не закрывает: `GrDateRangePicker`
работает с датами. Собирается из двух `GrDateTimePicker` с проверкой порядка на
стороне формы.

## `autoApply` здесь значит не то же, что у даты

У выбора одной даты клик по дню — это и есть готовое значение, и подтверждать
нечего. Здесь значение собирается минимум из двух частей, поэтому «применить»
означает «я закончил», а не повторяет уже сделанное. Дефолт — `true`: чаще
достаточно даты плюс часа, и лишняя кнопка на каждом выборе раздражает.
