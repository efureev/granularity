# GrDashboardPalette

Каталог виджетов, которые можно добавить на дашборд. Добавление — обычная
кнопка, поэтому клавиатурный сценарий существует по построению, а не
дорисовывается к перетаскиванию.

Запись раскладки — [`../model.md`](../model.md), клавиши —
[`../keyboard.md`](../keyboard.md), роли и объявления —
[`../a11y.md`](../a11y.md), токены — [`../theming.md`](../theming.md).

```vue
<GrDashboardPalette :items="available" @add="addWidget" />
```

## Когда брать

- **набор виджетов выбирает пользователь** — дашборд собирается из каталога, а
  не приходит готовым;
- **доступное зависит от роли или тарифа** — список приходит пропом, и
  недоступное просто не попадает в него;
- **карточка каталога нестандартная** — слот `item` рисует иконку, описание,
  превью;
- **добавлять пока нечего** — слот `empty` объясняет почему, вместо пустого
  прямоугольника.

## Когда взять другое

| Нужно | Берите |
| --- | --- |
| Выбрать один вариант из списка | [`GrSelect`](../../../granularity/docs/components/GrSelect.md) |
| Найти команду или объект поиском | [`GrCommandPalette`](../../../granularity/docs/components/GrCommandPalette.md) |
| Показать список без добавления | [`GrList`](../../../granularity/docs/components/GrList.md) |
| Объяснить, что дашборд пуст | [`GrEmptyState`](../../../granularity/docs/components/GrEmptyState.md) |
| Сама сетка | [`GrDashboard`](./GrDashboard.md) |

Несмотря на название, это **не** `GrCommandPalette`: там ищут команду по всему
приложению вводом с клавиатуры, здесь выбирают виджет из короткого известного
набора.

## Куда встаёт добавленный виджет — решает приложение

Компонент излучает намерение с описанием виджета, а координаты назначает
потребитель: он один знает, добавлять новый виджет вниз, в первое свободное
место или на позицию, с которой пользователь начал. Класть его «куда-нибудь»
означало бы портить раскладку, которую человек только что собрал.

## Перетаскивание — усиление, а не контракт

Плитку можно перетащить на сетку (`draggable`, включено по умолчанию), но кнопка
«Добавить» при этом остаётся и остаётся единственным клавиатурным путём. Сделай
перетаскивание контрактом — и каталогом нельзя пользоваться с клавиатуры, а
«доступность потом» здесь не наступает.

Куда бросили, сообщает сетка эмитом `itemDrop`, и кладёт по-прежнему приложение —
ровно как по кнопке. **Сетка, которая `itemDrop` не слушает, покажет подложку и
по отпусканию не сделает ничего**: либо обработайте событие, либо выключите
`draggable`.

Нажатие на саму кнопку переносом не становится: иначе дрогнувшая на пять
пикселей рука давала бы перенос вместо добавления.

## Границы

**Пальцем плитка не тащится.** Перенос касанием требует `touch-action: none` на
плитке, а каталог — вертикальный список, который на телефоне обязан
прокручиваться. Отбирать у скроллера вертикальную ось ради жеста, у которого уже
есть работающий эквивалент, — плохой обмен; на сенсорном вводе остаётся кнопка.
