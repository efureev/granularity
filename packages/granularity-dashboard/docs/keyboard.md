# Клавиатура

Перенос обязан иметь клавиатурный эквивалент — иначе сеткой не может пользоваться никто, кроме
владельца мыши. Ниже — фактическое поведение, проверяемое юнит-тестами пакета.

## Карта клавиш

| Где | Клавиша | Что делает |
| --- | --- | --- |
| ручка переноса | `Space` / `Enter` | взять виджет; повторно — положить |
| ручка переноса, взято | `←` `→` `↑` `↓` | двигать на одну ячейку |
| ручка переноса, взято | `Esc` | отменить, вернуть на исходное место |
| ручка переноса, свободно | `←` `→` `↑` `↓` | фокус на соседнюю ручку в порядке раскладки |
| ручка переноса, свободно | `Home` / `End` | к первому / последнему виджету |
| ручка размера | `←` `→` | ± колонка |
| ручка размера | `↑` `↓` | ± строка |
| ручка размера | `Shift` + стрелка | крупный шаг, три ячейки |
| ручка размера | `Home` / `End` | к `min` / `max` |
| каталог | `Enter` / `Space` | добавить виджет в сетку |

## Одна остановка `Tab` на сетку

Между ручками переноса водят стрелки (roving tabindex): сорок виджетов не должны стоить сорока
нажатий `Tab` по дороге к следующему блоку страницы. Ручка размера — своя остановка, по образцу
разделителя `GrSplitter` ядра.

В режиме `view` ручек нет **вовсе** — не скрыты, а не отрисованы. Скрытая, но фокусируемая кнопка
хуже отсутствующей: она попадает в обход и ничего не делает.

## Взятое не остаётся взятым

Уход фокуса за пределы сетки при взятом виджете отменяет перенос. Иначе состояние «виджет в руках»
пережило бы переход на другую страницу интерфейса, и следующая стрелка двигала бы то, чего
пользователь уже не видит.

## Что происходит по стрелке вниз

При компактизации `vertical` виджет, сдвинутый в пустоту под собой, всплывает обратно — это
определение компактизации, а не потеря нажатия. Свободное перемещение по вертикали даёт
`compact="none"`.

## Указатель

`Esc` во время переноса мышью тоже отменяет: браузер на него `pointercancel` не шлёт, поэтому
компонент слушает клавишу сам. Обрыв жеста системой (переключение окна, системный жест) возвращает
раскладку к той, что была до нажатия, — отпускание, наоборот, коммитит.
