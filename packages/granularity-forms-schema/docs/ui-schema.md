# `uiSchema`: раскладка и поведение

Схема описывает данные. Всё, что относится к виду, живёт отдельно — иначе
описание контракта пришлось бы править ради ширины колонки.

Ключ — **шаблонный** путь (`items.*.qty`), а не путь конкретной строки: правило
для повторителя пишется один раз и переживает удаление любой строки.

## Что можно

| Поле | Что задаёт |
| --- | --- |
| `layout.columns` | число колонок сетки, в том числе по брейкпойнтам |
| `layout.sections` | разделы: заголовок, описание, состав полей |
| `order` | порядок полей; `'*'` — место для неперечисленных |
| `hidden` | поле не рисуется вовсе |
| `fields[path].label` / `hint` / `placeholder` | тексты поверх схемы |
| `fields[path].widget` / `component` | подмена виджета |
| `fields[path].controlProps` | пропы контрола поверх посчитанных реестром |
| `fields[path].span` | ширина поля в колонках |
| `fields[path].when` | условие показа |
| `fields[path].readonly` / `disabled` | флаг или условие |
| `fields[path].array` | настройки повторителя |

## Условия

```ts
const equality: GrUiCondition = { path: 'type', eq: 'company' }
const either: GrUiCondition = { any: [{ path: 'a', truthy: true }, { path: 'b', gte: 10 }] }
// Сосед в той же строке повторителя.
const sibling: GrUiCondition = { path: '../kind', eq: 'disc' }
```

Относительный путь — единственный способ сослаться на соседнее поле строки
повторителя: абсолютный пришлось бы писать по индексу, а он меняется при каждом
удалении.

Пустота (`empty`) считается по правилу ядра: `0` и `false` пустыми не считаются,
иначе поле пряталось бы там, где форма считает его заполненным.

## Скрытое поле не проверяется

Поле, скрытое условием, выпадает и из правил: иначе отправка блокировалась бы
обязательностью поля, которого нет на экране.

## Порядок без потерь

Список `order` без `'*'` не теряет неперечисленные поля — они дописываются в
конец. Иначе добавленное в схему поле молча исчезало бы из формы.
