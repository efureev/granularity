# Серверный рендер

Пакет изоморфен: он не трогает `window`, `document` и `navigator` в `setup`.

## Что делается на сервере

Схема разбирается, модель собирается из умолчаний, правила компилируются,
разметка формы рендерится целиком. Всё это чистые функции.

## Что не делается

Живой регион повторителя создаётся при первом объявлении, то есть только в
браузере: `useAnnouncer` ядра ставит хост в документ, которого на сервере нет.

Фокус после добавления и удаления строки переносится в `nextTick` — на сервере
этот код не выполняется вовсе.

## Схема, пришедшая асинхронно

Если схема загружается с бэкенда после монтирования, модель соберётся при её
появлении. Чтобы сброс формы возвращал «как после загрузки», а не пустоту,
позовите `setSnapshot()` из `defineExpose` после того, как данные приехали.
