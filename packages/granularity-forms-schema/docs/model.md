# Нейтральная модель схемы

Между чужой схемой и формой стоит одна структура — `GrSchemaModel`. Адаптеры
приводят к ней zod и JSON Schema, а реестр рендереров и компилятор правил знают
только её.

Модуль `./model` не импортирует **ничего**: ни Vue, ни ядра, ни схемных
библиотек. От этого зависит, впишется ли третий адаптер (valibot, OpenAPI,
генератор на бэкенде) без переделки пакета.

## Модель сериализуема

`pattern` хранится строкой, а не `RegExp`; `date` — вид значения, а не тип.
Причина прикладная: модель отдают с сервера и кладут в кеш, а `JSON.parse` не
воскрешает ни регулярку, ни дату.

Побочная польза — `RegExp` с флагом `g` двигает `lastIndex` между вызовами и на
втором прогоне врёт; компилируя регулярку на месте, пакет снимает флаги `g` и `y`.

## Два вида пути

| Путь | Пример | Адресует |
| --- | --- | --- |
| шаблонный | `items.*.name` | описание: ключ в `uiSchema`, реестре, имени слота |
| инстанс | `items.0.name` | данные: `GrFormField name`, ключ в `GrFormRules` |

Их смешение — главный источник ошибок в генераторах форм. Развёртку делает
чистая функция `expandFields(root, value)`: узел элемента массива один, а полей
столько, сколько строк лежит в модели.

## Что модель выражает, а что нет

Выражает: вид значения, формат, обязательность, `nullable`, умолчание,
единственное допустимое значение, варианты выбора, ограничения (границы, длина,
шаг, целочисленность, уникальность, файлы), аннотации `x-*`, ветвление по
дискриминатору (`kind: 'union'`) и свободные ключи со схемой значения.

Не выражает: условия (`if/then/else`, `not`), объединения без дискриминатора,
преобразования (`transform`), произвольные предикаты (`refine`). Такие узлы
помечаются флагом `residual`, и за них отвечает полная проверка самой схемой —
она же остаётся источником правды.

`residual` — не «на всякий случай», а признак того, что моделью узел не выражен.
Разобранное объединение его **не несёт**: форма сама рисует переключатель ветки,
и гонять ради него полную проверку незачем.

Непонятое адаптер не глотает: всё, что он не разобрал, приходит списком в
`model.warnings`.

## Ветвление

`GrSchemaUnionNode` — объект, у которого набор полей зависит от значения одного
ключа: способ доставки, тип платежа, вид документа.

```ts
const delivery = {
  kind: 'union',
  discriminator: 'kind', // ключ, по которому выбирается вариант
  // Варианты — объектные узлы; у каждого дискриминатор объявлен через `const`.
  variants: [
    { kind: 'object', title: 'Самовывоз', fields: [{ key: 'kind', const: 'pickup' }] },
    { kind: 'object', title: 'Курьер', fields: [{ key: 'kind', const: 'courier' }] },
  ],
}
```

Откуда берётся дискриминатор:

| Источник | Запись |
| --- | --- |
| zod | `z.discriminatedUnion('kind', […])` |
| OpenAPI | `oneOf` + `discriminator: { propertyName: 'kind' }` |
| чистая JSON Schema | `oneOf`, где один и тот же ключ у всех вариантов несёт `const` |

Не вывелся ни одним путём — узел остаётся `union`, но с `residual: true` и
предупреждением `unsupported-node`: выбрать вариант нечем, и значение целиком
уходит полной проверке.

Свойства рядом с `oneOf` принадлежат каждой ветке: адаптер сливает их в вариант,
как `allOf`. Поэтому общее поле не нужно повторять во всех вариантах.

Развёртка выбирает ветку по текущему значению дискриминатора: в списке полей
объединение приходит **одним** инстансом, а поля выбранного варианта — под ним
(`parent` равен имени объединения).

## Свободные ключи

`additionalProperties` со схемой значения даёт `additional: true` и
`additionalValue` — узел, которым рисуется значение любого введённого ключа:

```ts
const attributes = { kind: 'object', additional: true, additionalValue: { kind: 'string' } }
```

| Схема | `additional` | `additionalValue` |
| --- | --- | --- |
| `additionalProperties: { type: 'string' }` | `true` | узел строки |
| `additionalProperties: true` | `true` | нет |
| `z.object({…}).catchall(z.number())` | `true` | узел числа |
| обычный `z.object({…})` | `false` | нет |

Без `additionalValue` вводить нечего: ключи разрешены, но чем рисовать значение,
схема не сказала, — форма такой хвост не показывает.

## Начальные значения

Выбраны не по вкусу, а по тому, как ядро считает поле пустым (`isEmpty`: `null`,
`undefined`, пустая строка и пустой массив — пусты; `0` и `false` — нет):

| Узел | Значение | Почему |
| --- | --- | --- |
| строка | `''` | поле остаётся управляемым, `required` работает |
| число | `null` | `0` не пуст — `required` прошёл бы на нетронутом поле |
| булев | `false` | чекбоксу нужен булев; «обязан быть отмечен» — отдельная проверка |
| выбор | `null` | `''` дал бы фантомный выбранный вариант |
| массив | `[]` | обязательно заранее: писатель ядра создал бы объект |
| что угодно ещё | `null` | но никогда `undefined`: снимок модели теряет такие ключи |
