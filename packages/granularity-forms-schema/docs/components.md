# Компоненты `@feugene/granularity-forms-schema`

Пакет публикует одно семейство: форма из схемы и её части.

- [`GrSchemaForm`](./components/GrSchemaForm.md) — форма по схеме целиком;
  вместе с ней из того же subpath приходят `GrSchemaField` (одно поле по узлу) и
  `GrSchemaArrayField` (повторяемая секция).

## Правила страницы компонента

Жанр, обязательные секции и запрет на рукописные перечни пропов описаны один раз
в спецификации ядра: `packages/granularity/docs/components.md`, раздел «Страница
компонента».

Путь указан текстом, а не ссылкой, намеренно: относительная ссылка в чужой пакет
ломается в опубликованном тарболе, где рядом лежит только `dist` установленной
зависимости.
