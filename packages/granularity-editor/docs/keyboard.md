# Клавиатура

Фактическое поведение кода, проверяемое тестами пакета. Общие правила — те же, что у ядра
(`packages/granularity/docs/keyboard.md`): `Tab` ходит между виджетами, стрелки — внутри.

## Тулбар

Панель форматирования — `role="toolbar"` с роверной навигацией: **одна остановка `Tab` на весь
тулбар**, внутри ходят стрелками. У схемы «статья» десять кнопок, и без этого до самого текста
пришлось бы добираться десятью нажатиями.

| Клавиша | Действие |
| --- | --- |
| `Tab` | Внутрь тулбара и дальше в область ввода |
| `←` `→` | По кнопкам панели; на краях кольцуется |
| `Enter` `Space` | Применить формат к выделению |

Активная кнопка объявлена `aria-pressed` — подсветки скринридер не видит.

## Область ввода

Горячие клавиши — те, что даёт TipTap, и они привычны по любому текстовому редактору.

| Клавиша | Действие |
| --- | --- |
| `Ctrl`/`Cmd` + `B`, `I` | Жирный, курсив |
| `Ctrl`/`Cmd` + `Z`, `Shift`+`Z` | Отменить, вернуть |
| `Enter` | Новый абзац |
| `Shift` + `Enter` | Перенос строки внутри абзаца |
| `Tab` | **Уводит из поля**, а не вставляет отступ |

Последнее — намеренно. `Tab`, вставляющий символ, запирает пользователя клавиатуры внутри поля:
выйти из него становится нечем. Отступы в тексте задаются списками и цитатой, а не табуляцией.

## Что произносится вслух

Область ввода объявлена `role="textbox"` с `aria-multiline="true"`; имя приходит из `GrFormField`
или из `ariaLabel`, описание и текст ошибки — через `aria-describedby`. Форматирование диктор
сообщает сам, читая разметку: собственного живого региона у поля нет.
