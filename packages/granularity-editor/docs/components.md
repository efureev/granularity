# Компоненты пакета

| Компонент | Что делает |
| --- | --- |
| [`GrMarkdown`](./components/GrMarkdown.md) | Показ markdown: дерево узлов вместо `v-html`, перерисовка по блокам, длинный документ без виртуализации |
| [`GrRichText`](./components/GrRichText.md) | Поле форматированного текста: тулбар, пузырьковое меню, схема вместо санитайзера |

Жанр страницы компонента, обязательные секции и запрет на рукописные перечни пропов описаны один
раз — в `packages/granularity/docs/components.md`, раздел «Страница компонента». Путь простым
текстом, а не ссылкой: относительная ссылка в чужой пакет ломается в опубликованном тарболе, где
рядом лежит только `dist` установленной зависимости.
