# Модель данных

## Два входа, один внутренний вид

Наружу пакет принимает два вида данных, внутрь пропускает один.

```ts
// Объектный — то, что приходит от бэкенда после `map`.
const objects = [{ id: 'sales', label: 'Продажи', data: [{ x: new Date(), y: 42 }] }]

// Колоночный — не создаёт объект на точку и переживает десятки тысяч значений.
const columns = [{ id: 'sales', x: [0, 1, 2], y: [10, null, 30] }]

// Голый ряд — вход `GrSparkline` в девяти случаях из десяти.
const row = [10, 12, null, 18]
```

Заданы оба (`data` и пара `x`/`y`) — выигрывает `data`, в консоль уходит предупреждение.

**Вид входа определяет первый непустой элемент, а не нулевой.** Ряд вполне может начинаться с пропуска, и по
`input[0]` голый ряд неотличим от списка серий.

## Пропуск — это не ноль

`null` в ряду означает «значения не было». Линия в этом месте **рвётся**, точка не рисуется, в таблице данных стоит
прочерк. Соединить соседей прямой или подставить ноль значило бы нарисовать значение, которого не существовало.

`NaN`, `±Infinity` и `undefined` приводятся к `null` — молча и без исключения: данные из внешнего API пестрят ими, а
падать графику незачем.

## Шкалы

| Тип | Когда | Что внутри |
| --- | --- | --- |
| `linear` | `x` — числа | значение как есть |
| `time` | `x` — `Date` | epoch ms |
| `band` | `x` — строки | индекс категории |

Тип выводится из первого непустого `x`, проп `xScale` всегда сильнее.

У категориальной шкалы `scale(i)` отдаёт **центр** полосы, а не левый край, как в d3: линия и маркеры ставятся по
центру категории, курсор ищет ближайший центр, а столбец рисуется от `center − bandwidth/2`.

## Деления

Числовая ось — «красивые числа» Хекберта: шаг всегда `{1, 2, 5} × 10ᵏ`. Тот же рисунок, что у `d3.ticks`. Цена
известна: на неудобном диапазоне вроде `[0.3, 7.1]` алгоритм может дать четыре деления там, где просили шесть.

Ось времени — лестница интервалов от секунды до года. Месяцы и годы шагаются **календарём**, а не фиксированным
числом миллисекунд: иначе 31-дневные месяцы уползают, а на переводе часов появляется дубль деления либо пропадает
одно.

## Инварианты

| Ситуация | Что происходит |
| --- | --- |
| дубли `x` | не схлопываются; точка адресуется индексом |
| несортированный вход | `linear`/`time` сортируются; у `band` порядок входа и есть порядок оси |
| пустая серия | остаётся в легенде и **удерживает свой индекс палитры** — иначе цвета скачут при фильтрации |
| все значения равны | домен разводится на половину единицы: ось из одной линии не читается |
| одна точка | линии нет, есть маркер; он встаёт в середину холста |
| скрытая серия | не растягивает ось и не даёт позиций |

## Арифметика отдельно от компонентов

Всё перечисленное живёт в `@feugene/granularity-charts/chart` и не зависит ни от Vue, ни от DOM — по нему строят свою
разметку, когда готового компонента не хватает:

```ts
import { linearTicks, normalizeChartData } from '@feugene/granularity-charts/chart'
```
