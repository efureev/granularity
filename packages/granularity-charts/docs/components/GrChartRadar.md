# GrChartRadar

Профиль по нескольким осям и сравнение профилей. Отвечает на вопрос, которого не
закрывают ни столбцы, ни круг: не «сколько» и не «из чего», а **какой формы**.

Выравнивание осей и две шкалы радиуса — [`../model.md`](../model.md), роли и
объявления — [`../a11y.md`](../a11y.md), клавиши —
[`../keyboard.md`](../keyboard.md), токены — [`../theming.md`](../theming.md).

```vue
<GrChartRadar :series="series" aria-label="Профиль компетенций" />
```

## Когда брать

- **форма профиля по нескольким метрикам** — компетенции, оценки по критериям,
  характеристики модели: важен силуэт целиком, а не отдельное значение;
- **сравнение двух-трёх профилей** — «было и стало», «мы и конкурент»,
  «кандидат и вакансия»: наложенные контуры сравниваются одним взглядом;
- **осей от трёх до восьми** — меньше трёх фигуры не получается, больше десяти
  спицы сливаются и подписи налезают;
- **метрики разнородные** — `axisScale: 'per-axis'` даёт каждой оси свой домен,
  и сравнивается только форма.

## Когда взять другое

| Нужно | Берите |
| --- | --- |
| Сравнить конкретные величины между собой | [`GrChartBar`](./GrChartBar.md) |
| Показать, из чего состоит целое | [`GrChartPie`](./GrChartPie.md) |
| Показать ход значения во времени | [`GrChartLine`](./GrChartLine.md) |
| Показать одно значение с подписью | [`GrStatistic`](../../../granularity/docs/components/GrStatistic.md) |

Точные значения по радару **не читаются**: площадь растёт как квадрат радиуса, и
глаз систематически преувеличивает разницу. Нужны величины — берите столбцы, а
радар оставьте там, где вопрос и правда про форму.

## Две шкалы радиуса — и обе с ценой

| Режим | Домен | Чем платим |
| --- | --- | --- |
| `shared` (по умолчанию) | один на все оси | разнородные метрики свести нельзя: та, что крупнее, займёт шкалу целиком |
| `per-axis` | свой на каждую ось | площади фигур сравнивать нельзя — сравнивается только форма |

Доля живёт только в расчёте радиуса. Собственное значение точки остаётся
исходным во всех режимах: протеки нормировка в данные — тултип и скрытая
таблица начали бы показывать проценты вместо величин.

## Оси выравниваются до нормализации

Число спиц обязано быть постоянным. У декартовых графиков позиции считаются по
видимым сериям, и это верно; на полярных ломает рисунок — спрячь легендой
единственную серию, знавшую про ось, и паутина провернётся. Поэтому каждая серия
дополняется пропусками до общего набора осей, а пропуск позицию удерживает.

Разрыв рвёт контур и **снимает заливку** этой серии целиком: замкнуть контур
через пропуск значит нарисовать ребро, которого нет, а залить рваный контур —
площадь, которой нет.
