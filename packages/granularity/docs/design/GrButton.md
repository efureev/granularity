# Дизайн GrButton

Четыре направления дизайна кнопки на одном API. «Эволюция» реализована в пакете,
«Тактильная», «Чертёж» и «Глина» — концепты для тем и будущих версий. Пропы, слоты,
пять весов, восемь тонов и шкала высот у всех общие; отличаются вид, движение и
правила, по которым кнопка показывает состояние.

Поведение реализованной кнопки — [`../components/GrButton.md`](../components/GrButton.md),
токены — [`../tokens.md`](../tokens.md), темы — [`../theming.md`](../theming.md).
Макеты всех четырёх версий — в приложении дизайн-системы [`apps/design`](../../../../apps/design/README.md)
(`yarn dev:design`).

## Эволюция — реализована

Тот же API и те же токены, дотянуты детали. Все решения уже в коде и описаны на
странице компонента; здесь — сводка значений.

| Решение | Значение | Где задаётся |
| --- | --- | --- |
| Вес подписи | 500 | `--gr-button-font-weight` |
| Фокус | `outline` 2px с отступом 2px, только `:focus-visible` | `--gr-ring` |
| Нажатие | `scale(.98)` без reduced-motion, тень внутрь у solid | `--gr-button-shadow-active` |
| Загрузка без префикса | спиннер поверх подписи, ширина та же, курсор `progress` | `GrButton.vue` |
| Иконка и зазор | 14 / 16 / 16 / 20px и 4 / 6 / 8 / 8px; отступ со стороны аддона на 2px меньше | подсказка ступени для `GrIcon` |
| Рамки весов | secondary 38 % тона, outline 70 %, под указателем — 100 % | `--gr-button-{tone}-border-soft`, `-border` |
| Нейтральная secondary | поверхность карточки, рамка, тень | `--gr-button-neutral-*`, `--gr-shadow-1` |
| Объём solid | блик 1px и тень | `--gr-button-shadow` |
| Наведение soft | тон 10 % и 16 % в саму soft-заливку | `--gr-button-{tone}-soft-bg-hover`, `-active` |
| Ссылка наружу | значок и «(откроется в новой вкладке)» | `gr.button.opensInNewTab` |
| Длинная подпись | многоточие, полный текст в подсказке | `GrButton.vue` |
| Зона касания | 44px на `pointer: coarse` через `::after` | `--gr-button-touch-size` |
| Шов в группе | светлая линия 1px между solid-звеньями | `--gr-button-divider` |

## Тактильная — концепт

Кнопка как предмет: свет сверху, тень снизу, отклик телом.

**Объём solid-кнопки.** Заливка тона, поверх — градиент белого от 14 % до нуля на
60 % высоты. Линия света по верхней кромке — `inset 0 1px 0` белого 24 % (в тёмной
теме 18 %), нижняя кромка — `inset 0 -1px 0` чёрного 14 % (32 %). Рамка — тон,
смешанный с чёрным на 16 %. Тень двухслойная: `0 1px 2px` нейтральная и
`0 6px 14px -6px` цвета заливки — 42 % в светлой теме, 62 % в тёмной.

**Веса.** secondary — тонированная пластина с внутренней рамкой 24 % тона и линией
света; outline — рамка 45 % тона; ghost и ghost-border — подложка проявляется под
указателем. Нейтральная primary — чернильная (цвет текста страницы) и инвертируется
в тёмной теме.

**Движение.**

| Событие | Что движется | Длительность | Кривая |
| --- | --- | --- | --- |
| Наведение | подъём на 1px, тень до `0 12px 24px -8px` | 240 мс | `cubic-bezier(.34, 1.56, .64, 1)` |
| Подложка ghost | `scale(.88 → 1)`, прозрачность 0 → 1 | 280 мс | та же пружина |
| Нажатие | `scale(.98)`, тень `inset 0 2px 5px` | 80 мс | `cubic-bezier(.2, .8, .2, 1)` |
| Фокус | отступ контура 6 → 2px | 220 мс | пружина |
| Иконки | стрелка +3px, плюс 90°, шеврон 180° | 260 мс | пружина |
| Загрузка | блик проходит по поверхности | 1600 мс | linear, по кругу |

С `prefers-reduced-motion` сдвигов, масштаба и блика нет, спиннер замедлен до 2.2 с.

**Состояния.** Недоступная — штриховка `135°` по `--gr-disabled-bg`, у outline рамка
становится пунктиром: состояние читается и без цвета. Радиус по ступени 8 / 8 / 10 /
12px; капсула — `--gr-button-radius: 999px` на теме.

**Что нужно для реализации.** Радиус и тени ложатся на существующие хуки —
`--gr-button-radius`, `--gr-button-shadow`, `--gr-button-shadow-active`. Новые
точки: фоновый градиент solid (хук `background-image`), тень цвета тона (токен на
тон), подъём под указателем (хук `transform`). Подложка ghost требует `::before` —
`::after` уже занят зоной касания.

## Чертёж — концепт

Кнопка без объёма: заливка, линия и шрифт. Тени, блики и градиенты не
используются.

**Линия хода** — главный сигнал. Под указателем по нижней кромке прочерчивается
линия 2px цветом тона (у solid — подписью на 65 %): `scaleX(0 → 1)` слева за
180 мс, `cubic-bezier(.2, 0, 0, 1)`. Сигнал одинаков у всех весов, поэтому ghost
ведёт себя как ссылка или вкладка, а ряд ghost-кнопок читается навигацией. В
нажатии линия полной яркости, заливка темнее, кнопка не двигается.

**Форма и шрифт.** Угол 3px на всех ступенях, рамка 1px у всех весов. Подпись —
600, без трекинга; на `sm` кегль 13/18. Иконка слева стоит в квадратной ячейке
высотой с кнопку, за перегородкой в 24 % цвета подписи. Счётчики и клавиши —
моноширинный шрифт в рамке 1px, у счётчика до 10 — ведущий ноль. Меню обозначено
залитым треугольником.

**Веса.** secondary — тонированная плашка с рамкой 32 % тона, outline — контур
62 %, ghost — только подпись, ghost-border — контур под указателем.

**Состояния.**

| Состояние | Вид |
| --- | --- |
| Фокус | контур 2px с отступом 3px, появляется за 80 мс |
| Загрузка | отрезок в 36 % ширины бежит по нижней кромке за 1.1 с; подпись видна на 86 % |
| Недоступная | заливка уходит у всех весов, остаётся пунктир 1px `--gr-brd-hover` и подпись `--gr-disabled-fg` |
| reduced-motion | линия появляется сразу; отрезок загрузки не выключается, а замедляется до 2.6 с — другого сигнала у загрузки нет |

**Группы.** Склеенный ряд — рамки внахлёст, внутренние углы 0. Между solid-звеньями
шов рисуется рамкой в 35 % подписи.

**Что нужно для реализации.** Тени снимаются темой: `--gr-button-shadow: none`,
угол — `--gr-button-radius: 3px`. Линию хода придётся рисовать `::before`: `::after`
занят зоной касания. Ячейка иконки требует обёртки слота `#prefix` в разметке
кнопки, бегущий отрезок — своего вида загрузки вместо спиннера.

## Глина — концепт

Тёплая бумага, графитовые чернила и одна глиняная точка на экран. Палитра — брендовая
палитра Anthropic (Ivory, Slate, Clay, Oat и тёплые серые). Шрифты системные: гротеск
в интерфейсе, Georgia в заголовках вокруг кнопок.

**Правила.**

- Главное действие поверхности — графитовая кнопка. Глина — одна на экран: то, ради
  чего экран открыт.
- Тон живёт в заливке и подписи. Рамки всегда тёплые серые — графит на 15 % и 30 %;
  у outline любого тона рамка одна и та же.
- Прозрачные кнопки под указателем получают оттенок бумаги
  `rgba(115, 114, 108, .1)`, в нажатии — `.18`.
- Залитые под указателем уходят прочь от цвета подписи: под графитовой подписью
  заливка светлеет, под светлой — темнеет. Контраст в наведении только растёт.
- Кнопка не двигается и не светится; переходы — 150 мс, `ease`.
- Подпись — гротеск 500; серифом набраны только заголовки вокруг кнопок.

**Тоны.**

| Тон | Заливка | Подпись | Контраст | Происхождение |
| --- | --- | --- | --- | --- |
| `neutral` | Slate `#141413` | Ivory `#faf9f5` | 17.6:1 | бренд |
| `primary` | Clay `#d97757` | графит | 5.9:1 | бренд |
| `success` | Olive `#788c5d` | графит | 5.0:1 | бренд |
| `warning` | `#c9a82d` | графит | 8.0:1 | бренд |
| `danger` | Brick `#b8433a` | Ivory | 4.6:1 | выведен: красного для интерфейса в бренде нет |
| `info` | `#2268bf` | Ivory | 5.3:1 | брендовый `#2a78d6` на шаг темнее: с белым он даёт 4.4 |
| `slate` | Gray 650 `#4d4c48` | Ivory | 8.2:1 | тёплый серый бренда |
| `azure` | Sky `#6a9bcc` | графит | 6.3:1 | бренд |

Светлые земляные тона несут графитовую подпись: белая на глине даёт 3:1 и не
проходит AA. Цвет тона в тексте на подложке взят темнее брендового — глина
`#973f22`, небо `#335d86`, — чтобы держать 4.5:1 и в нажатой подложке.

**Состояния.**

| Состояние | Вид |
| --- | --- |
| Фокус | синий контур 2px с отступом 2px — `#2a78d6`, в тёмной теме `#6aa3e8`; единственный холодный цвет на тёплой бумаге |
| Загрузка | свет проходит по подписи за 1.8 с; подпись и ширина на месте |
| Недоступная | заливка `#f0eee6`, подпись `#9c9a92` — бумага без чернил |
| reduced-motion | мерцания нет, подпись приглушена до 70 % |

**Форма.** Радиус 6 / 8 / 8 / 10px по ступеням. Иконки — линейный штрих 1.5px с
круглыми концами. Клавиши и счётчики — плашки без рамки: оттенок бумаги или 16 %
цвета подписи на заливке.

**Группы.** Звенья не склеены рамками, а лежат в общем лотке цвета бумаги с зазором
и полями 2px. Выбранное звено — белый лист с тонкой рамкой поверх лотка.

**Тёмная тема.** Фон — тёплый серый 800 `#262624`, поверхности — 750 `#30302e`,
подпись — Ivory. Главная кнопка инвертируется: Ivory с графитовой подписью. Глина
остаётся глиной; оттенок наведения — Ivory на 8 %, рамки — на 14 % и 28 %.

**Что нужно для реализации.** Палитра собирается темой через `createTheme` и
покомпонентные `--gr-button-{tone}-*`; при этом смысловые роли сдвигаются —
`neutral` становится главной кнопкой, `primary` — акцентом. Свои токены нужны
рамкам (тёплый серый вместо тона) и оттенку наведения прозрачных кнопок. Код
потребуют мерцание подписи вместо спиннера и группа-лоток вместо склейки.
