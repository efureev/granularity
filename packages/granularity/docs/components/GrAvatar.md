# GrAvatar

Аватар с изображением, инициалами или произвольным содержимым; круглый или
квадратный, со статусом и группировкой в ряд.

## Когда брать

- **человека или сущность узнают по картинке** — список участников, автор комментария, владелец задачи;
- **картинки может не быть** — откат идёт по цепочке: `src`, `fallbackSrc`, инициалы из `name`, слот;
- **нужен статус присутствия** — точка на аватаре вместо отдельного значка рядом;
- **участников несколько** — `GrAvatarGroup` собирает их в ряд с наложением и счётчиком.

## Когда взять другое

| Нужно | Берите |
| --- | --- |
| Изображение нужно рассмотреть | [`GrImageViewer`](./GrImageViewer.md) |
| Показывается иконка, а не человек | [`GrIcon`](./GrIcon.md) |
| Нужен счётчик поверх контрола | [`GrBadgeWrap`](./GrBadgeWrap.md) |
| Статус текстом | [`GrBadge`](./GrBadge.md) |

## Что показывается

Порядок отката: `src` → `fallbackSrc` → инициалы из `name` → слот по умолчанию.

```vue
<GrAvatar src="https://cdn.example/u/42.png" fallback-src="/avatar.svg" name="Ada Lovelace" />
```

Битая ссылка обрабатывается: по `@error` компонент переходит к следующему
варианту, и браузер не рисует иконку сломанного изображения. Смена `src`
сбрасывает ошибку — новая ссылка не наследует судьбу прошлой.

Пока картинка едет, её место держит скелет: иначе ряд аватаров мигает пустыми
кружками.

## Имя и инициалы

`name` даёт инициалы (первые буквы двух первых слов) и доступное имя. Когда есть
картинка, имя несёт её `alt`; без картинки роль `img` и имя берёт на себя сам
аватар — иначе кружок с инициалами для диктора пуст. `alt` сильнее `name`, слот
сильнее инициалов.

Функция инициалов доступна отдельно: `import { initialsFrom } from '@feugene/granularity'`.

Кегль считается от диаметра — треть, но не меньше 10px. Размер аватара бывает
произвольным числом пикселей, поэтому карта по ступеням шкалы его не закрывает.
Правило одно на инициалы, слотовый текст и счётчик «+N» у `GrAvatarGroup`: они
стоят в одном ряду, и разные пропорции читались бы как сбой.

## Автоцвет по имени

`autoColor` красит фон по имени: одинаковое имя всегда даёт одинаковый цвет,
поэтому человека в списке можно узнать по пятну ещё до чтения инициалов.

Выключен по умолчанию и включается на всё приложение через `GrConfigProvider`:

```vue
<GrConfigProvider :component-defaults="{ GrAvatar: { autoColor: true } }">
```

Серый аватар — осознанный нейтральный дефолт: цветной кружок спорит с
оформлением там, где аватар стоит внутри плотного интерфейса. Поэтому включение
остаётся решением приложения, а не библиотеки.

**Палитры внутри компонента нет.** Шесть слотов (`--gr-avatar-1-bg`/`-fg` …
`-6-`) объявлены в **теме самого компонента** (`components/GrAvatar/themes/`),
и каждый по умолчанию ссылается на пару `-light`/`-text` готового тона — ту же,
на которой стоит мягкий вариант `GrBadge`. Компонент считает только номер слота.

В глобальную тему палитра не идёт намеренно: она нужна одному компоненту, и
там за неё платил бы и тот, кто `GrAvatar` не берёт. Тёмного файла у палитры
нет — слот ссылается на роль, а роль переключается вместе с темой сама.

Приложению, которому не нужен пале-красный или пале-зелёный аватар, достаточно
переопределить слот:

```css
:root { --gr-avatar-4-bg: var(--gr-slate-light); --gr-avatar-4-fg: var(--gr-slate-text); }
```

Три тона из шести семантические, и это выбор, а не недосмотр: тона бледные, а
в ряду людей цвет читается как идентичность, не как состояние. Ровно для
несогласных существует переопределение выше.

Цвет виден только под инициалами: картинка закрывает фон целиком, а у пустого
аватара красить нечего. Счётчик «+N» у `GrAvatarGroup` тоже остаётся
нейтральным — это не участник, имени у него нет.

Контраст пары и различимость слотов держит гейт
`src/__tests__/avatarPalette.test.ts` — в обеих темах сразу.

## Статус

```vue
<GrAvatar name="Ada Lovelace" status="online" />
```

`online | offline | busy | away`. Точка декоративна (`aria-hidden`), а статус
объявляется словом из локали (`gr.avatar.status.*`): цвет сам по себе смысл не
передаёт.

## Ряд участников

```vue
<GrAvatarGroup :max="3" :total="9" aria-label="Команда релиза">
  <GrAvatar v-for="member in team" :key="member.id" :name="member.name" />
</GrAvatarGroup>
```

`max` ограничивает число видимых аватаров, остаток сворачивается в «+N»; `total`
нужен, когда в слоте лежит лишь часть участников. Группа объявлена
`role="group"`, а её имя содержит и подпись, и число скрытых — диктор слышит
«Команда релиза, и ещё 6», а не набор безымянных картинок.

`size` и `shape` группы доходят до детей через контекст, чтобы ряд не расползался.

## Размер и форма

`size` принимает ступень шкалы (`xs`…`lg`, читается из `GrConfigProvider`) или
число пикселей — у аватара исторически произвольный диаметр. `shape`
(`circle | square`) тоже настраивается глобально через
`componentDefaults.GrAvatar.shape`.
