# Токены `GrBadge` по темам

Слой бейджа существует затем, что нужный вес заливки у режимов разный: в светлом
filled-бейдж берёт `--gr-{tone}-solid` (иначе читался бы тяжёлой почти чёрной
плашкой), в тёмном — пастельный `--gr-{tone}` с тёмным текстом. Матрица весов —
`docs/modes.md`, раздел «Токены компонентов по темам».

У «Глины» (`clay/`) светлые земляные тона — глина, олива, горчица, небо — в светлом
режиме, а кирпич и синий в тёмном берут заливкой роль `-text`: точка-маркер того же
тона иначе сливалась бы с мягкой подложкой бейджа (гейт `grBadgeContrast`).
Подпись filled-бейджа на такой заливке — карточка или фон режима.
