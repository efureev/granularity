# Токены `GrAvatar` по темам

Палитра автоцвета — только ссылки на роли тонов. Слоты живут у компонента, а не в
глобальной теме: нужны ровно ему, и в глобальной за них платил бы и тот, кто
`GrAvatar` не берёт.

Файлов режимов нет, и это не пропуск: слот ссылается на пару `-light`/`-text`,
которая сама переключается с режимом. `primary` в палитру не входит — у него нет
`-light` (мягкая подложка бренда называется `--gr-accent`).
