# Клавиатура

Кадрирование мышью и пальцем очевидно, клавиатурой — нет: рамка неподвижна, и
«двигать» пользователь может только изображение под ней. Поэтому окно кадра само
получает фокус и слушает клавиши.

| Клавиша | Что делает |
| --- | --- |
| `Tab` | ставит фокус на окно кадра, затем на слайдер увеличения |
| `←` `→` `↑` `↓` | двигают изображение под рамкой на 12 px |
| `+` / `=` | увеличивают |
| `-` | уменьшают |
| `Home` | возвращает исходный кадр: центр, увеличение `1` |

Сдвиг направлен «за клавишей», а не «за картинкой»: `→` показывает то, что было
правее, то есть изображение уходит влево. Обратное направление читается как
инверсия у трети пользователей — здесь выбран вариант, совпадающий с прокруткой.

Окно кадра выпадает из таб-порядка (`tabindex="-1"`), пока картинки нет или
компонент отключён: фокусировать пустую рамку не на чем.

Увеличение доступно и с клавиатуры окна, и через слайдер — второй нужен для
указателя и для скринридера, который объявляет текущее значение. Общий
клавиатурный контракт дизайн-системы — `packages/granularity/docs/keyboard.md`.
