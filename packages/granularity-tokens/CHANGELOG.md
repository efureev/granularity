# Changelog

All notable changes to the [`@feugene/granularity-tokens`](.) package are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres
to [Semantic Versioning](https://semver.org/).

## [Unreleased]

### Changed

- **Триггер `GrColorPicker` под указателем — как поле во всех темах каталога.**
  `--gr-color-picker-trigger-hover-brd` у «Сланца» 1.4.0 и «Чертежа» 1.3.0 — `--gr-input-hover`
  вместо `--gr-primary`, как уже было у «Глины»; «Тактильная» 1.3.0 наследует это у «Сланца».

## [v2.3.1] 2026-10-27

### Fixed

- **«Глина» 2.0.1: заливка `slate` под указателем и в нажатии работает и без `color-mix`.**
  В тёмном режиме `--gr-slate-solid-hover` и `-active` были формулой `color-mix` — роль, а
  не производное, и фолбэка `@supports` сборка темы для неё не считает: в браузере без
  `color-mix` роль была недействительной, а экспорт токенов в форматы дизайн-инструментов
  получал ссылку CSS вместо цвета. Теперь — литералы того же цвета (`#575653`, `#53524e`).
  Гейт `roleFormulaFallback` не даёт роли быть формулой без фолбэка ни в одной теме
  каталога.

## [v2.3.0] 2026-10-26

Минор: «Глина» целиком из темы. Новые роли и основа разводят то, что у одной темы
совпадает, а у другой — нет; у «Сланца», «Тактильной» и «Чертежа» они ссылаются на прежние
роли, и их вид не меняется. Своя тема, которая не наследует тему каталога, обязана задать
новые роли и значения новых токенов компонентов ядра 3.2 — `doctor` назовёт недостающие.

### Added

- **Роли** `--gr-selected`, `--gr-selected-fg`, `--gr-selected-hover` (выбранное),
  `--gr-input-hover`, `--gr-input-focus-brd` и `--gr-control-brd-hover` (отклик рамки),
  `--gr-input-readonly-bg` и `--gr-input-readonly-brd` (поле только для чтения), `--gr-brd-strong`
  (граница плотнее разделителя); **основа** `--gr-font-display` (шрифт заголовков компонентов),
  `--gr-radius-overlay` (скругление всплывающей панели), `--gr-radius-control-{xs,sm,md,lg}`
  (скругление поля по ступеням) и `--gr-input-focus-ring-width` (толщина кольца фокуса поля). Тема без своего решения ставит
  ссылку на прежнюю роль — `var(--gr-primary)`, `var(--gr-input)`, `var(--gr-brd)`,
  `var(--gr-font-ui)`, `var(--gr-radius-xl)`. `--gr-input` описан как рамка поля ввода.
- **Значения новых токенов компонентов ядра** во всех темах каталога. «Сланец» 1.3.0,
  «Тактильная» и «Чертёж» 1.2.0 — вид прежний.

### Changed

- **«Глина» 2.0.0 — по макету «Глина · компоненты».** Палитра: бумага `#faf9f5`, белый лист
  карточки и всплывающих панелей, графит `#141413`, глина `#d97757`; рамки — графит 15 %,
  граница переключаемого контрола — 55 %, кольцо фокуса — синее `#2a78d6`; мягкие подложки тонов —
  13 % тона на бумаге (18 % в тёмном режиме). `azure` ушёл к бирюзе (`#5b9fb6`), чтобы не сливаться
  с `info`. `--gr-radius-control` — 8px. Кнопка: радиус по ступеням 6/8/8/10, без тени
  поверхности, мягкий вес — 13/19/25 % тона на бумаге. Пропсы по умолчанию: вкладки линией,
  метки `semi`, разделитель пути «/», ступень `sm` у пагинации и шагов, аватар без автоцвета,
  колонка подписи списка свойств 160px, прогресс без рамки.
- **«Глина» — то, что раньше было зашито в ядре.** Выбранное графитом с бумажным знаком, радио —
  сплошным кружком; рамка поля — графит 55 %, под указателем 75 %; плотная граница — 30 %.
  Заголовки карточки, окна, шторки и пустого состояния — антиква 20–22px, вес 500; подсказка —
  графитовый пузырь; пункты меню и опции — нейтральная подложка; сообщение без рамки, заголовок
  чернилами; шапка таблицы на листе; выбранный пункт боковой панели и заголовки групп без капса;
  заглушка — бегущим бликом; окно и шторка — тенью `--gr-shadow-3`, шторка скруглена по
  внутреннему краю. Кнопка: рамка контурной не меняется под указателем, у мягкого веса тонов
  рамки нет, нажатие без сжатия; у всего недоступного рамка в цвет заливки
  (`--gr-disabled-brd`). Зона загрузки — на бумаге пунктиром рамки поля, значок кругом; лента
  событий, аватар, пагинация, OTP — по макету; пустая звезда рейтинга — контуром. Поля:
  скругление 6/8/8/10 по ступеням, в фокусе — синяя рамка, только для чтения — без подложки с
  тонкой рамкой, кольцо фокуса — 1px. Строки выбранных файлов — плашки листа; тосты — в правом
  нижнем углу. Переключатель компактный — 24×14 … 36×20, с подписью состояния — 44 и 52px;
  под шапкой таблицы — линия 30 %, рамка первой строки под ней погашена. Пропсы: подсказка поля под полем, отмена в окнах — `ghost`, звёзды
  рейтинга — графит.

## [v2.2.0] 2026-10-22

### Added

- **Значения графиков и медиа в темах каталога.** Раздел `components/@feugene/granularity-charts/`
  — 20 токенов вида `theme` (толщины линий и прозрачности), `components/@feugene/granularity-media/`
  — маска кадра `GrImageCrop`. Значения — прежние литералы компонентов: вид не меняется.
- Темы: «Сланец» и «Глина» 1.2.0, «Тактильная» и «Чертёж» 1.1.0; `targets` называют
  `@feugene/granularity-charts` и `@feugene/granularity-media` `^3.0.0`.

## [v2.1.0] 2026-10-21

Темы каталога написаны под ядро 3.1: `targets` — `{ "@feugene/granularity": "^3.1.0" }`.

### Added

- **Тема «Тактильная» (`tactile`)** — наследник `slate`: кнопка-предмет со светом сверху, тенью
  цвета тона, подъёмом под указателем и пружиной в отклике; прозрачные веса откликаются
  подложкой, недоступная кнопка — штриховкой и пунктиром.
- **Тема «Чертёж» (`blueprint`)** — копия `slate`: плоская кнопка без теней, линия хода по нижней
  кромке, угол 3px, подпись 600, ячейка иконки и загрузка бегущим отрезком (пропсы по умолчанию
  темы).

### Changed

- «Сланец» и «Глина» 1.1.0 — значения новых токенов `GrButton`, повторяющие прежний вид.
- `theme:copy` копирует тему каталога без `extends` из исходника `themes/<id>` пакета: собранный
  манифест нужен только источнику с `extends`.

## [v2.0.0] 2026-10-21

Мажор: тема — полный набор значений, включая значения компонентов. Переезд — `docs/migration-3.md`
ядра.

### Added

- **Значения компонентов в теме** — раздел `components/<пакет>/<Компонент>/` исходника темы
  (`root.json`, `modes/<режим>.json`): «Сланец» и «Глина» несут значения токенов вида `theme`
  компонентов ядра. `defineTheme` сливает раздел наследника с родительским по токену.
- **Версия и целевые пакеты темы**: `version` и `targets` в `theme.json` и в `grThemeCatalog`;
  у тем каталога — `1.0.0` и `{ "@feugene/granularity": "^3.0.0" }`. `themes/<id>/theme.lock.json`
  — версия и отпечаток итоговых данных: правка значений без подъёма `version` роняет `generate`.
- **Копия темы** — `theme:copy` в монорепо, бинарь `gr-theme-copy` у пакета: обёртка над
  `copyTheme` granum, снимающая посчитанные фолбэки — их пересчитывает сборка темы.

### Changed

- **Исходник темы — раскладка granum, читает её загрузчик granum.** `theme.json` объявляет режимы
  объектом, пропсы по умолчанию — в `extensions.granularity.componentDefaults`, файл режима — плоские
  значения, его `extends` — в `theme.json`. Посторонний файл — ошибка; фолбэки в исходнике —
  ошибка. `@feugene/granum` — необязательная peer-зависимость `theme/node`.
- **«Глина» — копия «Сланца»**, а не наследник: все значения свои, правки «Сланца» в неё не приходят.
  Значения по парам — прежние.
- **У каталога нет темы по умолчанию**: `defaultTheme` у провайдера убран, сборка без `themes` —
  ошибка granum со списком тем. `GR_DEFAULT_THEME_ID` → `GR_BASE_THEME_ID` — базовая тема пакета.

### Fixed

- **Формулы производных — под `:where(:root), [data-theme]`.** В CSS без слоёв (`dist/themes/<id>.css`
  ядра) голый `:root` перебивал специфичностью значение, которым тема переопределяет формулу в
  своём режиме по умолчанию: у «Глины» на странице без атрибута наведение кнопок брало формулу
  реестра вместо своей.

## [v1.4.0] 2026-10-21

### Added

- **`loadThemeData(id)`** — полные данные темы каталога по требованию, для страниц, которые показывают
  значения включённой сейчас темы. У каждой темы свой чанк, загружается только запрошенная; тема не из
  каталога — отказ со списком тем. Данные те же, что у `themes/<id>/theme.json`: генератор пишет их
  модулями `src/theme-data/<id>.generated.ts`, гейт `--check` держит их в синхроне с темами.

## [v1.3.0] 2026-10-21

### Changed

- **`grThemeManifest()` — форма манифеста granum 3.8**: `{ themes: [{ id, title, modes, defaultMode }], defaultTheme, activation }`
  вместо `{ theme, modes, defaultMode, activation }`. Тип темы — `GrThemeManifestTheme`.

## [v1.2.0] 2026-10-20

### Added

- **Тема «Глина» — `clay`.** Тёплая бумага и графит, один акцент цвета глины; режимы
  `light` и `dark`, `extends: slate`. Свои значения всех ролей: поверхности, восемь тонов
  с подложками и текстом на них, пять серий графиков, кольцо фокуса. Подпись на светлых
  заливках — графитом, поэтому `hover`/`active` у `primary`, `success`, `warning` и `azure`
  тема переопределяет: заливка уходит к бумаге, а не к цвету подписи, и контраст при
  наведении не падает. Пропсы компонентов по умолчанию (`componentDefaults`): у
  `GrButton` загрузка светом по подписи, у `GrButtonGroup` — лоток.

### Fixed

- **`validateTheme` проверяет производное, которое тема переопределила.** Раньше контраст
  `-fg` на `-hover`/`-active` считался по формуле реестра, даже если режим объявил своё
  значение, — и тема с другой формулой проходила или падала не по своим цветам. Теперь
  считается то, что тема объявила: `color-mix` с ролью или с цветом, и находка называет
  токен темы, а не формулу реестра.

## [v1.1.0] 2026-10-20

### Added

- **`mode.fallbacks` у `createMode` и `extendMode`** — фолбэки `@supports not (color-mix)`,
  посчитанные от ролей самого режима, данными. В `modes.define` granum 3.4:
  `{ ...ocean.definition, fallbacks: ocean.fallbacks }` — без них браузер без `color-mix`
  получает hover и active базы. `definition` не меняется и годится для granum раньше 3.4.
- **`grThemeManifest()` несёт `activation.value`** — шаблон пары `{theme}-{mode}`, как манифест
  сборки granum; совпадение с `createThemeManifest` granum 3.4 держит тест.

### Docs

- **`docs/concepts.md`** — понятия: тема и что в неё входит, режим и что у него есть, пара, активная
  тема и превью, режим приложения, где режим действует, словарь.
- README темы `slate`: страница темы на портале есть — `granularity.tech/themes/slate`.

## [v1.0.0] 2026-10-19

### Added

- **`docs/themes.md`** — что тема обязана объявить, суффиксы ролей и ловушки контраста, свой
  режим (`extendMode`, `createMode`, `tone`), своя тема (`loadTheme`), превью и проверка перед
  выкладкой. Раздел переехал из `docs/theming.md` ядра целиком.
- **Выпуск тегом `granularity-tokens-v*`** — своя джоба CI (линт, типы, гейт генератора, тесты,
  сборка, `publint`) и публикация в npm и GitHub Packages. Выпускается раньше ядра: ядро и
  спутники зависят от пакета диапазоном.
- **Пакет токенов и тем дизайн-системы.** Словарь токенов, данные тем и сборка темы вынесены из
  `@feugene/granularity`: реестр без значений (`tokens/foundation.json`, `roles.json`,
  `derived.json` — 101 примитив, 94 роли, 18 формул), тема `slate` в `themes/slate/` с режимами
  `light` и `dark`, каталог тем `grThemeCatalog`.
- **`defineTheme`** собирает тему целиком: наследование темы от темы и режима от режима, полнота по
  реестру, контраст и различимость тонов в каждом режиме, фолбэки производных для браузеров без
  `color-mix`. Результат — данные в форме `GranumThemeData` контракта granum 3.
- **`loadTheme`** (`/theme/node`) читает тему из папки, находит тему-базу по id и отдаёт
  прочитанные файлы в `sources`, а тему каталога в цепочке — в `extends`: по ней granum берёт
  токены компонентов для темы приложения в `theme` или `previews`.
- **Провайдер granum без компонентов — владелец каталога тем.** `granum.manifest.json` с каталогом
  (`slate`), реестром токенов (`themes/registry.json`) и формулами производных (`tokens.css` на
  `:root, [data-theme]`); сборка — `granumProvider()` granum 3. Ядро подключает пакет
  зависимостью провайдера.
- **`extendMode`, `createMode`** — режим поверх готового и с нуля (были `extendTheme`/`createTheme`
  в `@feugene/granularity/theme`). Базой служит любой режим любой темы: `'dark'` встроенной,
  `{ theme, mode }` темы данными или другой собранный режим. Результат — полный набор ролей, CSS
  под парой `<тема>-<режим>` и `definition` — готовый вход `modes.define` конфига granum с одними
  отличиями. Покомпонентные токены сверяются с `knownComponentTokens`, если список передан.
- `tone`, `validateTheme`, цветовая математика и `applyTheme` — те же, что были в
  `@feugene/granularity/theme`. `GR_BUILTIN_THEME` и схемы встроенных режимов генерируются из темы
  по умолчанию.
- Гейты значений идут по каждой паре «тема × режим»: различимость тонов, запрет тона в роли текста,
  граница контрола, палитра графиков, тени по режимам, полнота и каталог.
- **`grThemeManifest(id?)` и `GR_DEFAULT_THEME_ID`.** Манифест режимов темы каталога в форме
  `virtual:granum/themes` — для приложения без плагина granum, подключившего готовый
  `themes/<id>.css`: пары по правилу granum по умолчанию (`data-theme`, `<тема>-<режим>`).

### Changed

- **Тени `--gr-shadow-1..3` — только роли режима.** Примитивом остаётся `--gr-shadow-0`: тень,
  объявленная и в `:root`, и в режиме, при равной специфичности решалась порядком файлов.
