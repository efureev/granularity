# Темы

Тема — полный набор значений токенов дизайн-языка: примитивы (`root.json`), роли каждого режима
(`modes/<режим>.json`) и метаданные (`theme.json`). Режимы — варианты внутри темы: `light` главный,
`dark` стандартный второй, дальше любые. Понятия целиком — [`docs/concepts.md`](../docs/concepts.md).

| Тема | Название | Режимы | Характер | Дизайн-система |
| --- | --- | --- | --- | --- |
| `slate` | Сланец | `light`, `dark` | холодные нейтрали, индиго-акцент, контраст по AA | [granularity.tech/themes/slate](https://granularity.tech/themes/slate) |
| `clay` | Глина | `light`, `dark` | тёплая бумага, графитовые чернила, один глиняный акцент; наследует `slate` | [granularity.tech/themes/clay](https://granularity.tech/themes/clay) |

Каждая тема — папка с `README.md`: для чего она, правила использования, которых нет в токенах, и
ссылка на её дизайн-систему.

## Как выбрать

Тема выбирается на сборке приложения — `theme: '<slug>'` в конфиге granum, по умолчанию `slate`.
В CSS приложения едет одна тема, режимы переключаются в рантайме парой
`data-theme="<slug>-<режим>"`.

## Раскладка папки

```
themes/<slug>/
  README.md        # описание и правила использования
  theme.json       # id, title, description, docs, extends?, defaultMode, modes
  root.json        # примитивы: палитра, шрифты, отступы, радиусы, движение
  modes/light.json # роли и тени режима
  modes/dark.json
  notes.json       # необязателен: пояснения к значениям для доки
```

- Имя папки — slug темы `^[a-z][a-z0-9-]*$`, оно же `id` в `theme.json`. Имя режима — без дефиса:
  на корне пара `<тема>-<режим>` разбирается по последнему дефису.
- Файлы значений — `{ "<токен без -->": "<значение>" }`, без селекторов: их назначает сборка
  приложения.
- Режим может хранить только отличия: `{ "extends": "dark", "tokens": { … } }`.
- Тема может наследовать другую: `"extends": "slate"` в `theme.json`, тогда в файлах — только то,
  что меняется.
- `docs` — абсолютный URL дизайн-системы темы, `https://granularity.tech/themes/<slug>`. Его же
  обязан называть `README.md` темы — это проверяет гейт `generated.test.ts`.

## Своя тема

Та же раскладка в коде приложения и `loadTheme` из `@feugene/granularity-tokens/theme/node`:
тема с `"extends": "slate"` объявляет только отличия, сборка проверяет полноту, контраст и
различимость тонов в каждом режиме и падает с именем токена. Собранная тема идёт в `theme`
(активная) или `previews` конфига granum. Пропсы компонентов по умолчанию — `componentDefaults` в
`theme.json`: они уезжают в `extensions.granularity` манифеста режимов.

## Новая встроенная тема

1. Папка `themes/<slug>/` с файлами выше и `README.md` по образцу `slate`.
2. `yarn workspace @feugene/granularity-tokens generate` — каталог, справочник `docs/tokens.md`.
3. `yarn workspace @feugene/granularity-tokens test:run` — гейты значений идут по всем парам
   «тема × режим» сами.
