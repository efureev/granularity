# `GrBadge` в «Глине»

Светлые земляные тона — глина, олива, горчица, небо — в светлом режиме, а кирпич
и синий в тёмном берут заливкой роль `-text`: точка-маркер того же тона иначе
сливалась бы с мягкой подложкой бейджа (гейт `grBadgeContrast`). Подпись
filled-бейджа на такой заливке — карточка или фон режима.
