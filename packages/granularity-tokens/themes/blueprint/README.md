# Чертёж · `blueprint`

Плоская точность: заливка, линия и шрифт.

## Для чего

Инструменты и плотные таблицы — экраны, где кнопок много и они не должны спорить с данными. Без
теней, бликов и градиентов; главный сигнал — линия хода, прочерчиваемая по нижней кромке под
указателем. Тема — копия `slate` (`theme:copy`), а не наследник: самостоятельный язык, правки
«Сланца» в неё не приходят. Новый токен пакета компонентов «Чертёж» получает не молча, а находкой
`doctor`, и значение решает её автор.

## Правила использования

- **Линия хода одинакова у всех весов**: ряд `ghost`-кнопок читается навигацией — вкладками или
  ссылками. Кнопке, которая должна выглядеть действием, нужен вес с рамкой.
- **Кнопка не двигается**: в нажатии темнеет заливка, линия — полной яркости.
- **Иконка слева стоит в ячейке** высотой с кнопку, за перегородкой (`prefixCell`); подпись — 600.
- **Загрузка — отрезок, бегущий по нижней кромке** (`loadingIndicator: 'track'`): подпись и ширина
  на месте. С `prefers-reduced-motion` отрезок не выключается, а замедляется — другого сигнала у
  загрузки нет.
- **Недоступная кнопка — пунктир без заливки**: остаётся контур `--gr-brd-hover` и подпись
  `--gr-disabled-fg`.
- Угол 3px на всех ступенях, рамка 1px у всех весов.

## Режимы

| Режим | Назначение |
| --- | --- |
| `light` | режим по умолчанию: роли «Сланца» на момент копии |
| `dark` | тёмный режим «Сланца» на момент копии; кнопка так же плоская |

## Дизайн-система

[granularity.tech/themes/blueprint](https://granularity.tech/themes/blueprint) — режимы, образец и
роли темы на портале. Основы и компоненты темы целиком открываются в приложении дизайн-системы
монорепозитория: `yarn dev:design` (`apps/design`).

## Как подключить

`{ theme: 'blueprint' }` в `themes` конфига granum — основной темой или дополнительной. Без
granum — `@feugene/granularity/themes/blueprint/root.css` и файлы нужных режимов,
`themes/blueprint/light.css`, `themes/blueprint/dark.css`; целиком —
`@feugene/granularity/themes/blueprint.css`. Пропсы компонентов по умолчанию тема несёт в
манифесте тем: приложение отдаёт его плагину режимов ядра (`granularityThemePlugin`,
`initThemeEarly`).
