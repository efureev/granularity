# Сланец · `slate`

Холодные нейтрали шкалы slate, индиго-акцент и контраст, выверенный по AA в обоих режимах.

Тема называется по шкале, на которой построена (`--gr-slate-*`), и в конфиге (`{ theme: 'slate' }`) с
тоном `tone="slate"` не встречается.

## Для чего

Базовая тема дизайн-системы: продуктовые интерфейсы, админки, инструменты — плотные экраны, где
таблица, форма, алерт и ряд кнопок стоят рядом. Её значения — эталон: любая другая тема пакета
наследует `slate` и объявляет только отличия.

## Правила использования

- Цвет текста — из роли `-text`, а не из тона: насыщенный тон проваливает AA хотя бы в одном
  режиме (гейт `toneContrast`).
- Заливка кнопочного веса — `-solid` со своим `-solid-fg`: кнопки всех тонов выглядят одной семьёй.
- Граница переключаемого контрола — `--gr-control-brd`, а не `--gr-brd`: только она держит 3:1 к
  странице, карточке и `--gr-muted`.
- Ошибка валидации — роли `--gr-invalid-*`, а не danger-тон: по умолчанию это ссылка на danger, но
  разные сообщения тема вправе развести.

## Режимы

| Режим | Назначение |
| --- | --- |
| `light` | режим по умолчанию: светлые поверхности, синеватая полупрозрачная тень читается мягче чёрной |
| `dark` | светлая заливка тонов под тёмный текст; тень чернее и плотнее, подложка модальных слоёв плотнее — иначе поднятая поверхность не отделяется от фона |

## Дизайн-система

[granularity.tech/themes/slate](https://granularity.tech/themes/slate) — режимы, образец и роли
темы на портале. Основы и компоненты темы целиком открываются в приложении дизайн-системы
монорепозитория: `yarn dev:design` (`apps/design`).

## Как подключить

`{ theme: 'slate' }` в `themes` конфига granum — или ничего: `slate` — тема по умолчанию. Без granum —
`@feugene/granularity/themes/slate/root.css` и файлы нужных режимов, `themes/slate/light.css`,
`themes/slate/dark.css`; целиком — `@feugene/granularity/themes/slate.css`.
