# `GrImageViewer` в «Сланце»

Хром просмотрщика остаётся тёмным в любом режиме: рядом с фотографией светлая
панель спорит с содержимым и подсвечивает края кадра. Поэтому значения не
зависят от режима — токены нужны не для смены на тёмную, а чтобы тема или
приложение могли перекрасить хром под свой продукт.
