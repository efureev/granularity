# `GrBadge` в «Сланце»

Слой бейджа существует затем, что нужный вес заливки у режимов разный: в светлом
filled-бейдж берёт `--gr-{tone}-solid` (иначе читался бы тяжёлой почти чёрной
плашкой), в тёмном — пастельный `--gr-{tone}` с тёмным текстом. Матрица весов —
`docs/modes.md` ядра, раздел «Токены компонентов по темам».
