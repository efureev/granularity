# Вес гранулярных импортов

> Сгенерировано `yarn sizes:docs` по собранному `dist` пакета `@feugene/granularity-code` 1.0.2.
> Править руками бесполезно — правка потеряется на следующей сборке.

Сколько приезжает потребителю, взявшему один подпуть: gzip самого entry и всего, что он тянет
из `dist`. Общий код лежит в отдельных чанках, поэтому вес самого файла entry ничего не говорит.

**Складывать эти числа нельзя.** Общий чанк посчитан в каждой строке заново, а платится один раз: сумма 3 самых тяжёлых строк даёт 17.3 kB, а вместе они весят 13.9 kB. Вес набора считается объединением — так его и считает `yarn sizes`.

Это верхняя граница: бандлер приложения трясёт дерево дальше и минифицирует повторно.

| Компонент | gzip | файлов | от бареля |
| --- | ---: | ---: | ---: |
| `GrDiff` | 8.2 kB | 8 | 45 % |
| `GrCodeEditor` | 4.8 kB | 5 | 26 % |
| `GrCodeBlock` | 4.3 kB | 7 | 24 % |

Весь пакет из корня — 18.2 kB.
