# Вес гранулярных импортов

> Сгенерировано `yarn sizes:docs` по собранному `dist` пакета `@feugene/granularity-code` 0.1.0.
> Править руками бесполезно — правка потеряется на следующей сборке.

Сколько приезжает потребителю, взявшему один подпуть: gzip самого entry и всего, что он тянет
из `dist`. Общий код лежит в отдельных чанках, поэтому вес самого файла entry ничего не говорит.

**Складывать эти числа нельзя.** Общий чанк посчитан в каждой строке заново, а платится один раз: сумма 3 самых тяжёлых строк даёт 18.8 kB, а вместе они весят 15.3 kB. Вес набора считается объединением — так его и считает `yarn sizes`.

Это верхняя граница: бандлер приложения трясёт дерево дальше и минифицирует повторно.

| Компонент | gzip | файлов | от бареля |
| --- | ---: | ---: | ---: |
| `GrDiff` | 8.6 kB | 9 | 44 % |
| `GrCodeEditor` | 5.4 kB | 6 | 28 % |
| `GrCodeBlock` | 4.8 kB | 8 | 25 % |

Весь пакет из корня — 19.5 kB.
