# Клавиатурный контракт

| Компонент | Свои клавиши | Остановки `Tab` |
| --- | --- | --- |
| `GrCodeBlock` | своих нет. Блок встаёт в таб-порядок (`tabindex="0"`), когда он скроллер **по пропам** — задан `maxHeight` либо выключен `wrap`; листается стрелками и `PageUp`/`PageDown`. Кнопка копирования — обычная кнопка, своя остановка | блок (если скроллер) + кнопка |
| `GrDiff` | своих нет. Область сравнения — скроллер и потому в таб-порядке; кнопка раскрытия пропуска — обычная кнопка | область + кнопки пропусков |
| `GrCodeEditor` | всё, что даёт `defaultKeymap` CodeMirror: перемещение, выделение, `Ctrl`/`Cmd`+`Z` и `Shift`+`Ctrl`/`Cmd`+`Z` из `history`. `Tab` **уводит фокус** | редактируемая область |

## Почему `Tab` по умолчанию уводит фокус

Редактор кода в форме — контрол среди контролов, и выйти из него клавиатурой
обязано быть можно: иначе до кнопки «Сохранить» пользователь не доберётся,
а обойти ловушку мышью получится не у всех.

Отступ по `Tab` включается пропом `tabIndents`. Тогда работает штатный приём
CodeMirror: `Esc` возвращает `Tab` роль перехода, и подсказка об этом стоит под
полем — молча менять поведение клавиши нельзя.
